## ✨ معرفی

**Rayan Chat Widget** یک رابط چت آنلاین مستقل است که می‌تواند در وب‌سایت‌ها و پروژه‌های مختلف استفاده شود. این پروژه با React ساخته شده و از طریق API و WebSocket با سرویس چت ارتباط برقرار می‌کند.

ویجت به یک بک‌اند خاص وابسته نیست و می‌تواند به هر سرویس سازگار با قراردادهای API و رویدادهای بلادرنگ متصل شود.

## 🌟 امکانات

- نمایش ویجت چت در وب‌سایت
- ارسال و دریافت پیام
- دریافت پیام‌ها به‌صورت بلادرنگ
- نمایش وضعیت اتصال
- پشتیبانی از اتصال مجدد WebSocket
- رابط کاربری واکنش‌گرا برای موبایل و دسکتاپ
- قابلیت شخصی‌سازی ظاهر ویجت
- قابل build و میزبانی روی هاست استاتیک یا CDN
- معماری آماده برای توسعه و مشارکت جامعه متن‌باز

## 🛠️ فناوری‌ها

- React
- JavaScript یا TypeScript، مطابق تنظیمات پروژه
- CSS یا راهکار استایل استفاده‌شده در پروژه
- HTTP API
- WebSocket

## 🚀 نصب و اجرای پروژه

### پیش‌نیازها

- Node.js نسخه سازگار با پروژه
- یکی از مدیران بسته npm، pnpm یا yarn

### نصب وابستگی‌ها

```bash
npm install
```

### اجرای محیط توسعه

```bash
npm run dev
```

### ساخت نسخه production

```bash
npm run build
```

پس از build، خروجی پروژه را می‌توان روی هاست استاتیک یا CDN منتشر کرد.

> نام دقیق دستورات ممکن است با توجه به `package.json` پروژه تغییر کند.

## ⚙️ تنظیمات اتصال

نمونه تنظیمات عمومی:

```env
VITE_API_URL=https://api.example.com
VITE_WEBSOCKET_URL=wss://socket.example.com
```

نام متغیرها باید با تنظیمات واقعی پروژه هماهنگ باشد. اطلاعات محرمانه را در متغیرهایی که در مرورگر قابل مشاهده‌اند قرار ندهید.

## 🔌 قرارداد ارتباط با بک‌اند

ویجت برای کارکرد صحیح به سرویس‌هایی با قابلیت‌های زیر نیاز دارد:

- ایجاد یا بازیابی نشست چت
- دریافت فهرست پیام‌ها
- ارسال پیام جدید
- دریافت رویداد پیام جدید از طریق WebSocket
- احراز هویت یا شناسایی بازدیدکننده، در صورت نیاز

ساختار endpointها و payloadها باید در مستندات API پروژه ثبت شود تا اتصال ویجت به بک‌اندهای مختلف ساده باشد.

## 📦 استفاده در وب‌سایت

پس از build، فایل‌های خروجی را روی هاست یا CDN منتشر کنید و ویجت را در صفحه موردنظر mount کنید:

```jsx
import { createRoot } from 'react-dom/client';
import ChatWidget from './ChatWidget';

createRoot(document.getElementById('chat-widget')).render(
  <ChatWidget />
);
```

نمونه عنصر mount:

```html
<div id="chat-widget"></div>
```
